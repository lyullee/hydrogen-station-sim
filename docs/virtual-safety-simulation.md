# 가상 안전 대응 모의 기능

리모콘의 **안전 대응** 탭은 시뮬레이터 내부 상태만 변경한다. 실제 밸브, PLC, 팬, 전원, 경보 또는 대외 통보와 연결하지 않는다. 센서 상세의 활성 시나리오와 SAGA의 현재 상황별 대응 카드에도 같은 가상 명령 버튼을 표시한다.

## 공정과 조치 판정

- 트레일러 양단, 압축기 흡입·토출, 세 저장뱅크의 입·출구, 디스펜서 1·2를 개별 조작한다. 디스펜서 차단은 노즐 유로를 막아 해당 차량의 질량유량을 0으로 만든다. 공급 차단은 재충전 은행 선택과 압축기 이송량을 바꾼다. 뱅크 용기 자체의 누출은 연결 배관을 차단해도 용기 질량이 계속 감소한다.
- 명령 시각, 이동 완료 시각, 실제 위치, 피드백, 연결 유량을 별도로 기록한다. 고착·내부 누설·피드백 오류는 `failed`로 남는다. 격리 구간 압력은 마지막 연결 압력을 유지하는 *가상 계측값*이며, 별도 배관 체적과 열역학을 풀지는 않는다. 따라서 실제 잔압 계산값으로 사용하지 않는다.
- 각 계산 프레임에서 뱅크 압력, 노즐·압축기 유량, 온도, 누출 누적량, 가스검지, 피해영향 **표본 관측점**을 다시 계산한다. 조치 이력의 전후 수치와 훈련 재생표를 확인할 수 있다. 영향 표본 거리는 확정 대피거리나 시설 설계 안전거리로 해석하지 않는다.

## 방재·대피·복구

- 저장뱅크별 가상 벤트는 **0.5 mm 등가 구경**, **지상 6 m 상향 방출**이라는 모의 가정으로 해당 뱅크의 질량을 감소시킨다. 방출 유량과 가스검지·피해영향이 새로 계산된다. 실제 설계 벤트 용량이나 배출구 위치를 뜻하지 않는다.
- 냉각·살수 ON은 해당 뱅크 벽과 외기 사이에 **UA 1,800 W/K**의 모의 열교환을 더한다. 환기팬과 풍속·풍향은 가상 검지 농도에 단순 확산 배율로 작용한다. 기류·화염·분무의 3차원 CFD 모델이 아니며 대량 고압 누출의 분산 가능성을 보증하지 않는다.
- 구역별 인원·대피 명령·출입 통제·전원 격리를 기록하고 3D 화면에 사람의 집결지 이동과 상태 표시를 반영한다. 튜브트레일러와 차량 1·2는 해당 이송·충전 공정이 멈추고 차단밸브 실제 폐쇄·피드백·잔류 유량 확인이 끝나야 현장에서 이동시킬 수 있다. 이동한 차량의 운전을 다시 요청하려면 새 시뮬레이션이 필요하다. 차량의 용기 재고 상태는 해당 실행의 추세·재생용으로 남으며, 도로 주행이나 호스 탈거의 역학은 계산하지 않는다. 대응조직 통보 버튼은 가상 기록만 남긴다.
- 누출 수리는 활성 사고 입력을 제거한다. 기밀시험은 격리한 라인의 압력 유지와 밸브 내부 누설을 3초간 모의하고, 검지기 자체진단은 수신 품질을, 밸브 피드백 시험은 위치·고장 상태를 확인한다. 가상 불활성 퍼지는 해당 뱅크 **입·출구가 실제 닫힌 경우**에만 5초간 진행하고 라인 조성의 대리값을 0.5%까지 낮춘다. 단계적 재가압 시험은 퍼지된 *가상 격리 라인*을 25/50/100% 단계로 높여 본다. 이 절차는 뱅크 용기 질량을 추가하지 않는다. 불활성 가스 설비·실측 조성·별도 라인 체적은 아직 모델링하지 않았으므로 실제 퍼지·기밀·압력시험의 합격 판정이 아니다. 벤트 감압은 별도 명령이다.
- 재가동 전 활성 누출·가스 신호는 승인을 차단한다. 새로운 사고가 발생하면 이전 복구 확인 기록은 초기화된다. 실제 복구는 승인된 현장 절차, 작업허가, 기밀·계측 기능시험에 따라야 한다.

## 훈련 재생 및 비교

`GET /api/simulations/{id}/safety/replay`는 조치 타임라인과 프레임별 공정·위험 수치를 반환한다. `POST /api/simulations/{id}/safety/compare`는 두 실행의 누적 방출량, 최고 검지 농도, 첫 조치 지연, 조치 실패, 부적절한 복구 시도와 화재 중 벤트 방출 중첩을 비교한다. 점수와 차단 재검토 후보는 교육용 휴리스틱이며 실제 안전 판정이 아니다. 두 실행의 사고 입력 서명이 다르면 화면에 비교 주의 문구를 표시한다.
