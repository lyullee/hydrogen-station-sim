# 3D 도로·진출입로 및 외곽 보행 환경 보강

## 전면 도로 수정

- 기존 전면 도로를 새 아스팔트 표면으로 덮어 비정상적으로 보이던 횡단보도를 가렸다.
- 도로 진행 방향과 직각인 횡단보도를 외곽 위치에 다시 구성했다.
- 중앙 점선, 차로 가장자리선, 횡단보도 정지선, 배수구와 맨홀을 추가했다.
- 양쪽 연속 보도, 경계석 분할선과 외곽 가로등을 배치했다.

## 충전소 진입과 출구

- 전면 도로에서 충전 구역으로 연결되는 진입 차로와 출구 차로를 물리적으로 분리했다.
- 각 차로에 방향 화살표, 중앙 구분선과 정지선을 표시했다.
- 보도와 만나는 구간은 차도 표면을 연속시켜 차량의 출입 동선이 명확히 보이도록 했다.

## 주변 공간 채움

- 후면 건물군을 연결하는 서비스 도로와 양쪽 외곽 연결 도로를 추가했다.
- 외곽 녹지 두 곳에 주차장과 서로 다른 색상의 주차 차량을 배치했다.
- 전면 도로 건너편에는 유리 버스 정류장과 벤치를 추가했다.
- 충전소 내부가 아닌 도로 건너편 보도와 후면 건물가에만 보행자를 배치했다.
- 보행자는 서로 다른 속도와 구간으로 왕복하며 기존 자동 반투명 처리 대상에 포함된다.

## 모델 경계

- 도로, 차량 및 보행자는 3D 주변 환경 표현용이다.
- 교통 흐름, 충돌 위험, 공정 동특성 또는 HyRAM 위험 계산에는 연결하지 않았다.
- 별도의 실행 검증은 수행하지 않았다.
