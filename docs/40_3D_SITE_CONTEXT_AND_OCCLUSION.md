# 3D 주변 환경 및 시야 가림 처리

## 반영 내용

- 줄기, 가지, 다층 수관으로 구성된 디테일 나무를 충전소 외곽에 배치했다.
- 창문, 지붕, 간판이 있는 저층 연구·에너지 서비스·정비 건물을 주변 맥락으로 추가했다.
- 운영자, 방문자, 정비 인력이 서로 다른 보행 경로를 왕복하도록 구성했다.
- 팔과 다리의 보행 동작 및 미세한 상하 움직임을 적용했다.

## 시야 보호

- 나무, 주변 건물, 사람이 카메라와 현재 시선 중심 사이에 들어오는지 매 프레임 계산한다.
- 핵심 설비를 가리는 객체만 부드럽게 반투명 상태로 전환한다.
- 가림 상태에서 벗어나면 원래 불투명 상태로 복귀한다.
- 건물, 나무, 사람별로 서로 다른 최소 투명도를 적용했다.

## 모델 경계

- 주변 건물과 보행자는 3D 시각화 전용이다.
- 수소 공정 동특성, HyRAM 위험 계산 및 안전거리 판정에는 아직 연결하지 않았다.
- 별도의 실행 검증은 수행하지 않았다.
