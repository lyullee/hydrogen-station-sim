# 노드 계측·SAGA·라이브 사고 운전

관제 화면의 노드 선택기는 HAZOP DB의 23개 노드를 기준으로 PT/TT/FT 태그를 보여준다. 모델 신호 품질이 `GOOD`일 때만 값과 추세를 그리며, 별도 계측 모델이 없는 지점은 `미연결`로 표시한다. `센서` 상세창에는 모든 노드의 PT/TT/FT 현재값을 한 표로 보여준다. 추세 상세와 CSV는 선택 노드의 태그를 사용한다.

리모콘에서 운전 중 `선택 사고 투입`을 누르면 기존 상태를 재설정하지 않고 계산 루프의 다음 시점에 사고를 적용한다. 사고 카드의 시작·종료 시각은 운전 중에는 *현재 모의 시각으로부터의 지연·종료 시각*이다. `이 사고 종료`는 그 사고만 종료한다. 누출은 재고와 에너지에서 질량을 차감하며, 외부 화재·가열·냉각은 UA 열전달 항으로 물리 상태를 바꾼다. 이미 래치된 ESD는 사고 종료 후에도 자동 해제되지 않는다.

SAGA 연동은 로컬 Python SAGA의 `/api/digital-twin/hazop/direct`를 상태·센서 분석 경로로 사용한다. 관제 브라우저의 **자동 분석 ON/OFF** 버튼이 켜져 있으면 30초마다 현재 센서 신호와 기준을 전송하고, 주의·경보 서명이 바뀌면 즉시 추가 분석한다. 주의·경보 또는 명시적인 피해영향 요청에는 디지털 트윈 서버가 같은 스냅샷의 GOOD 압력·온도 센서로 먼저 피해영향을 계산하고, 계산 완료 결과를 직답 요청의 `impactResults`에 실어 보낸다. SAGA 직답 응답과 계산값을 합쳐 표시하며 일반 `/api/chat` 추론 경로로 우회하지 않는다. SAGA가 연결되지 않아도 디지털 트윈의 센서 판정과 확보된 계산값으로 직답한다. 화면의 답변은 직답 결과를 순차적으로 표시한다. 설정은 브라우저에 저장되며 OFF여도 수동 질문과 시나리오 생성·평가는 가능하다. 정상 운전에서는 피해영향 결과를 대화에 표시하지 않고, 주의·경보 또는 사용자의 명시적인 피해영향 요청에서만 설비·누출유량·열복사·과압·표본 범위를 카드로 표시한다. 질문 입력창 위의 추천 질문은 미리 준비된 목록에서 주기적으로 바뀌며 클릭 즉시 질문을 전송한다. `H2STATION_SAGA_URL` 환경변수로 SAGA 주소를 변경할 수 있으며 기본값은 `http://127.0.0.1:8090`이다. 필요하면 `H2STATION_SAGA_DIRECT_URL`로 직답 API 주소만 별도 지정할 수 있다. SAGA 대화창은 메인 관제 화면 안에 있다.

`시나리오 생성·평가`를 명시적으로 누른 경우에만 SAGA 생성형 대화 API가 최대 3개의 가상 누출 노드·직경 조합을 제안한다. 일반 질문의 피해영향은 현재 센서 기반 가정 사례로 직답 경로에서 계산한다. 생성형 모드에서는 SAGA가 시나리오별 압력·온도 태그를 고르고, 서버가 태그와 HAZOP 누출직경 목록(0.1/0.5/1/3 mm)을 검증해 피해영향예측 엔진에 전달한다. 계산값은 두 번째 SAGA 프롬프트로 되돌려 비교·해석한다. 이 과정은 공정에 사고를 주입하거나 설비를 조작하지 않는다. 실제 누출이 없는 제안은 모두 가정 결과로 표시한다.

HyRAM의 5 kW/m² 열유속 및 5 kPa 과압 기준을 1·3·5 m 관측점에서 검사해 **표본 영향 거리**를 표시한다. 가장 먼 관측점에서도 기준을 넘으면 `이상`으로, 모든 관측점에서 미달이면 `범위 미확정`으로 표시한다. 3D 링은 개념 배치에 나타나는 시각 보조물이며 부지 설계도나 법정 이격거리가 아니다.

공정도/3D의 가상 CCTV는 설비별로 생성한 서로 다른 정지 이미지다. 고·중·저압 저장뱅크는 서로 다른 랙 및 용기 외관으로 만들었다. 형상과 계통 구성은 [FIBA의 수소 압력용기 설명](https://www.fibatech.com/hydrogen-pressure-vessels-2/), [PDC의 충전소 압축·저장·예냉 공정 구성](https://www.pdcmachines.com/wp-content/uploads/2023/02/PDC_Brochure_V21_USA_SM.pdf)을 참고한 시각적 예시다. 화면의 설비 수치 사양은 `scenario.py` 참조 모델의 값이며 실물 제작사 데이터시트가 아니다.
