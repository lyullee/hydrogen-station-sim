# 2번 디스펜서 3D 참조 오류 수정

## 증상

- 3D 모델 초기화 시 `standby is not defined` 오류가 발생했다.
- 오류 오버레이가 표시되고 충전소 3D 장면이 생성되지 않았다.

## 원인

- 2번 충전 호스와 노즐을 추가하면서 장비 ID인 `standby`를 JavaScript 객체 변수처럼 참조했다.
- 실제 2번 디스펜서의 3D 그룹 변수는 `compactDispenser`이다.

## 수정

- 2번 호스 끝점의 좌표 변환 대상을 `compactDispenser`로 변경했다.
- 2번 호스와 노즐의 부모 객체를 `compactDispenser`로 통일했다.
- 기존 장비 ID와 물리 모델/API 연결은 변경하지 않았다.

## 확인 범위

- 사용자 화면에 표시된 초기화 오류의 직접 원인만 수정했다.
- 별도의 실행 검증은 수행하지 않았다.
