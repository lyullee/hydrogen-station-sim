# Asset navigation and detector fixtures

Date: 2026-09-19

## Added

- Collapsible equipment list with names and subsystem tags.
- Shared selection behavior between list and mesh picking.
- List selection opens the existing equipment data card; the focus button moves toward the selected equipment.
- Two illustrative overhead hydrogen detector fixtures above the dispenser positions, with sensor head, mounting body, wiring and identification plates.
- Detector cards explicitly state visual-only status and absence of concentration/ESD-input coupling.
