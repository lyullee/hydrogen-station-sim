# Compact dispenser envelope based on a manufacturer reference

Date: 2026-09-19

## Primary source

Nel, 70 MPa CAR dispenser DI001, Version 1.0, copyright 2017:

https://nelhydrogen.com/wp-content/uploads/2019/11/DI001-Technical-specification.pdf

The public one-page specification was retrieved. It lists a 520 mm by 520 mm footprint and 2500 mm height, a 2.5 m hose, start/stop controls and a backlit electronic display. These are historical reference specifications, not a claim about current products.

## Implemented visual interpretation

The second, visual-only dispenser now has a 0.52 x 0.52 x 2.50 scene-unit casing, treating one unit as approximately one meter. Its casing is placed above the existing island. A compact head band, front display, start/stop buttons, lower access panel, coupling, flexible hose and nozzle holder were added. The existing island and protection-post arrangement remain.

The screen continues to identify the unit as visual-only. The equipment card states the reference envelope and distinguishes interpreted geometry from actual manufacturer CAD. Earlier second-dispenser details are hidden, not represented as a second overlapping operational unit.

## Limits

Only the casing envelope is dimensionally referenced. Hose length, internal routing, fitting sizes, panel layout, installation details and surrounding safety distances were not engineered or certified. No proprietary CAD or manufacturer identity is reproduced. The active first dispenser, physics and API are unchanged.

The previously disclosed active vehicle-hose coordinate issue remains awaiting user approval. No tests, execution, browser review or verification were performed.
