# 대형 모니터 관제 UI 적용 — 2026-09-27

승인된 `designs/monitor-20260927`의 배치를 실제 `web/` 관제 화면에 적용했다. 실행 주소는 http://127.0.0.1:8000/ 이며, 8789 포트는 독립 디자인 시안이다.

## 화면 구성

- 1600×900 논리 보드를 화면 크기에 맞춰 균일 확대/축소한다. 메인 화면에는 페이지/패널 스크롤이 없다. 비율이 다른 디스플레이에는 여백이 생긴다.
- 왼쪽 16:9 공통 영역에서 기존 3D와 공정 흐름도를 전환한다. 실제 설비 모델과 상호작용을 유지했다.
- 오른쪽에 실시간 분석, 저장 뱅크, 압축기/냉각 출구, 두 디스펜서, 7개 가상 가스검지기를 배치했다.
- 아래에 압력/온도/유량의 최근 120초 추세를 동시에 표시한다. 전체 이력, 재생, 최신 프레임 복귀, CSV는 추세 상세에서 제공한다.
- HAZOP와 사고 영향 요약은 기존 분석의 이상 판정에 따라 표시한다. 사고 입력이 0건이어도 실제 HAZOP 임계값 경고는 표시된다. 기존 래치/운전 조건은 변경하지 않았다.
- 전체 모니터와 3D 단독 전체화면을 분리했다. 전체화면에서도 카메라 마커 좌표와 렌더링 해상도를 보정한다.
- CCTV, 설비, 센서, 계산 상태, 사고 상세는 별도 대화상자로 제공한다. 상세 이력/표에는 필요시 스크롤을 허용한다.
- 리모콘은 별도 창으로 유지하고 색상만 통일했다. 68개 시나리오/15개 사고 종류와 공정 실행 API는 유지했다.

## 데이터 및 구현

`monitor-wall.js`는 기존 `station-frame` 이벤트와 선택된 프레임을 읽는 표시 계층이다. `monitor-wall.css`가 관제 배치를 담당한다. 미수신은 `—`로 표시한다. 프리쿨러 출구는 TT-1201/TT-1601의 GOOD 신호만 사용한다. 디스펜서와 뱅크는 모델 상태값을 사용하므로 진단 센서 편향과 물리 상태의 구분이 유지된다.

기존 ID와 상세 DOM 노드는 유지해 원래 갱신/리모콘/이력 핸들러를 재사용했다. 공정 방정식, HAZOP 규칙, 안전 PLC, HyRAM 계산은 변경하지 않았다. 가스검지기는 모델 추정값, CCTV는 AI 정지 이미지라는 기존 표기를 유지한다.

WebGL 초기화 실패 시에도 관제 배치와 공정 흐름 화면을 사용할 수 있다. 시안에 있던 예시 수치는 실제 화면에 사용하지 않는다.
