## 관점별 정확도 해석

### 1. 계산 엔진과 소프트웨어

현재 가장 강하게 말할 수 있는 부분은 재현성이다. 기록된 전체 회귀 실행은 1,571개 테스트가 모두 통과했고, LLM 근거·SAGA 계약·가상 안전·HAZOP·HIAD 핵심 경로 159개 테스트도 모두 통과했다. 이는 계산 경로, API 계약, HAZOP·안전조치 실행, LLM 근거 전달이 서로 깨지지 않는다는 뜻이다. 물리 모델이 현장값을 항상 같은 오차로 맞춘다는 의미는 아니다.

### 2. 저장용기·충전 경계 모델

공개 Type-IV 탱크 12개 독립 holdout에서 압력 RMSE 3.84 MPa, 온도 RMSE 4.83 °C, SOC RMSE 3.85 %p가 기록됐다. 따라서 “공개 탱크 충전 경계조건을 재현하는 검증된 모델”이라고 표현할 수 있다. 차량 탱크 형상, 실제 디스펜서 제어, 충전소 전체 폐루프의 정확도로 확장해서 표현하면 안 된다.

### 3. 누출·방출·화재 영향

Ekoto 결과는 누출 질량유량 과도응답의 정량 근거를 제공한다. PRESLHY 최초 동결평가는 기준을 통과하지 못했고, 개선 후 72.7% 수치는 사후 개발 진단으로만 사용한다. 점화 압력 피크는 27개 holdout 모두가 사전 오차 기준을 만족했다. 다만 이 결과는 특정 실험 형상에 대한 결과이므로 H70 충전소의 법정 이격거리, 야외 제트화염 복사거리, 실제 대피거리의 정확도를 뜻하지 않는다. 위험거리는 시나리오 입력과 HyRAM 계산에 따른 모델 결과로 표시해야 한다.

### 4. 현장 데이터 적용성

비식별 현장 로그에서는 재충전 압력 예측 394건의 MAE 0.184 MPa와 P90 오차 0.529 MPa가 확인됐다. 압력·유량·순서의 station-side 재현성은 확보됐지만, 현장 데이터에 차량 수용탱크·디스펜서·컨트롤러가 동일 시간축으로 결합된 독립 full-loop 원자료가 없어 station-to-vehicle 정확도는 산출하지 않았다.

### 5. SAGA·LLM 의사결정 지원

SAGA는 센서값, 사고 시나리오, 피해영향 계산, 공개 사고근거를 분리해 전달하고, 정상상태와 비상상태를 구분해 응답하도록 계약 검증을 통과했다. HIAD 34개 HRS 사례가 34/34 추적되고, 9개 실행 가능한 사고군 레시피가 모두 디지털 트윈 경로를 통과한다. 이것은 “근거가 연결된 대응안 생성”의 검증이며, LLM의 답변이 현장 조치를 보장하거나 운영자의 대응시간·정확도를 개선한다는 임상·인간평가 결과는 아니다.

## 현재 정확도라고 부를 수 없는 항목

- 충전소 전체 station-to-vehicle 폐루프 정확도
- 모든 설비 형상에서의 절대 피해거리·법정 안전거리
- 실제 사고 빈도, 점화확률, 인명피해 확률
- LLM이 운영자의 안전성과 대응시간을 개선한다는 효과
- 규제 적합성 또는 현장 운전 승인

현재 전체 증거 게이트에는 11개 실패와 7개 보류가 남아 있고, 그중 제한된 IJHE 제출판정을 막는 게이트는 9개다. 이 항목들은 외부 원자료의 계측·형상·동기화 정보가 부족하거나, 현재 모델이 해당 실험 기준을 만족하지 못한 결과다. 실패 결과를 숨기거나 평균 정확도에 섞지 않고 제한사항으로 공개하는 것이 안전하다.

## 홍보자료에 사용할 수 있는 문장

> 본 시스템은 공개 독립 holdout과 비식별 현장 station-side 로그를 이용해 저장용기 충전, 제한된 방출 질량유량, 점화 후 압력 피크, 충전 재시작 압력 예측을 검증했다. HyRAM 기반 피해영향 계산과 SAGA의 사고근거·단계별 대응 연결도 자동 검증하며, 실패한 감압 전이 결과도 함께 공개한다.

다음 표현은 사용하지 않는다: “현장 전체 정확도 92.2%”, “모든 사고거리 정확”, “LLM이 안전을 보장”, “규제 인증 완료”. 92.2%는 물리 정확도의 평균이 아니라 현재 연구범위 증거 게이트의 폐쇄율이다.
