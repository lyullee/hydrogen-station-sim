# H₂ Operations · Design 02

운영 애플리케이션에 적용하지 않은 독립 UI 디자인 시안입니다. 원본 `web/` 및 공정 계산 코드는 수정하지 않았습니다.

- 밝은 정보 패널과 어두운 16:9 3D 뷰를 조합했습니다.
- 저장뱅크, 압축기, 예냉기, 디스펜서, 가스 검지를 오른쪽에 모았습니다.
- 위쪽 요약은 작은 숫자와 단위 중심으로, 아래쪽은 압력·온도·유량 추세로 구성했습니다.
- 정상 / 이상 버튼으로 상태별 레이아웃을 비교할 수 있습니다. HAZOP 및 HyRAM 안내는 이상 시안에서만 나타납니다.
- 3D / 공정 흐름 전환, 3D 시점 변경, 카메라 사진, 전체화면, 리모콘 디자인을 확인할 수 있습니다.
- 모든 계측값·추세·이력·임계값은 시안용 샘플입니다. 백엔드 API 호출 및 실제 운전 명령은 없습니다.
- 기존 Three.js 설비 모델과 AI 생성 CCTV 사진을 복사해 사용했습니다. 3D 배치는 UI 검토를 위한 별도 참조 배치입니다.

이 폴더에서 `python -m http.server 8789 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8789/`를 여세요. Three.js 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 HTTP 미리보기를 사용해야 합니다.

## 대형 모니터 표시 모드

- 1600×900 기준 관제 화면 전체를 뷰포트의 가로·세로에 맞춰 비례 확대/축소합니다. 16:9 이외 화면에서는 필요한 여백만 두고 모든 정보를 표시합니다.
- 기존 모바일 세로 재배치 대신 고정된 관제 배치를 유지합니다. 패널을 잘라내거나 데이터 영역을 스크롤하도록 만들지 않았습니다.
- 주요 상태 글자와 계측값 크기를 늘렸고, 4K 등 고해상도에서는 화면과 함께 확대됩니다.
- 상단 **전체 모니터**는 관제 화면 전체를, 뷰 상단 확장 아이콘은 3D/공정도만 전체화면으로 표시합니다. Esc로 복귀할 수 있습니다.
- `wall-fit.js`는 표시 크기만 조정합니다. 운영 앱 및 공정 API에는 여전히 연결하지 않았습니다.
- 1366×768, 1920×1080, 2560×1440, 3840×2160 각각 정상/이상 2상태 총 8개 화면에서 페이지 넘침, 패널 내부 잘림, 하단 상태줄 겹침 없음과 16:9 뷰 비율을 확인했습니다. 결과: `wall-layout-validation.json`.
- 변경 전 시안: `before-wall-layout/`. 최종 FHD 이미지: `preview-wall-fhd.png`.
