# Imamura 2008 development evidence

The release-network diagnostic reads the Imamura et al. (2008) Figure 3 arrays
from Sandia's public HyRAM+ 6.1 validation test:

`tests/hyram/validation/test_heatflux.py`, class `Test_Imamura_2008`.

The HyRAM+ repository is available at
<https://github.com/sandialabs/hyram/tree/v6.1> and is licensed under GNU GPL
v3. The raw HyRAM checkout is intentionally excluded from this repository. The
analysis result records the exact source-file SHA-256 so a local checkout can be
verified.

These numerical outcomes were inspected before the present comparison was
formalized. They are therefore **development-only**, not a prospective holdout
and not independent confirmatory evidence for this project.

Original citation recorded by HyRAM+: Imamura T, Mogi T, Wada Y, *Science and
Technology of Energetic Materials* 2008;69(1):7–11.
