# Proust 90 MPa derived coordinates

`proust_90mpa_release.csv` contains independently digitized factual coordinates
from Figure 5 and measured temperatures transcribed from Table 1 of:

> C. Proust, D. Jamois, E. Studer, “High pressure hydrogen fires,”
> *International Journal of Hydrogen Energy* 36(3), 2367–2373 (2011),
> DOI: 10.1016/j.ijhydene.2010.04.055.

The source PDF is not redistributed. No data-redistribution licence was found
for the public conference paper. The repository's MIT licence applies to the
extraction and evaluation software; it does not grant rights in the source paper.

`proust_90mpa_extraction.json` records the source checksum, axis calibration,
two digitization passes, uncertainty and the protocol commit that preceded
numerical access. Values below the frozen 220 K primary window remain in the
metadata but are not included in the primary CSV.
