# 독립 검증 원자료 요청 패키지

기준일: 2026-10-14

이 문서는 Schefer/Sandia, Grüne/KIT, JRC GasTeF, Cal State LA HRS 연구진 또는 데이터 관리자가 검토할 수 있는 **비발송 요청 초안**이다. 자동 발송하지 않으며, 원자료를 저장소에 복사하지 않는다. 자료를 받더라도 수치 결과를 보기 전에 평가 프로토콜·모델 커밋·분할 기준을 고정한다.

## 요청 목적

station-side 수소충전소 디지털 트윈의 압력·온도·유량·방출 경계를 독립적으로 재현하고, 공개 실험 또는 실제 운전 자료로 구성요소 검증을 수행한다. 차량과 충전소의 공통 시계열이 제공되지 않으면 station-to-vehicle 전체 검증으로 주장하지 않는다.

## 공통 최소 자료

각 이벤트 또는 시험에 대해 다음 항목만 있어도 1차 적합성 검토가 가능하다.

| 역할 | 최소 입력 |
|---|---|
| 시간축 | 공통 경과시간(s), 샘플 주기, 시작·종료 정의 |
| 경계상태 | 초기·시간별 압력, 온도, 외기압 또는 후단압력 |
| 유동 | 질량유량 또는 누적 질량, 오리피스/노즐 직경, 밸브 개방 시각 |
| 용기 | 유효 체적, 형상·벽/라이너 열물성, 초기 충전량 |
| 조건 | 가스 종류·상, 방출/충전 방향, 주변온도, 환기 또는 풍향 |
| 품질 | 단위·교정 불확도·결측 규칙·센서 위치와 채널 매핑 |

## 기관별 요청 항목

### 1. JRC GasTeF

- Type-III/IV 탱크 fast-fill 시험의 공통 경과시간 압력·가스온도·벽온도·입구 온도·질량유량
- pre-cooling 온도, 초기 탱크 상태, 목표 압력, 충전 종료 조건
- 공개 가능한 시험 ID와 시험군 분할 정보
- 원시 로그를 공개할 수 없으면, JRC 보관 상태에서 고정 프로토콜을 실행하고 시험별 예측-측정 오차와 해시만 반환하는 custodian 평가

공개 기록은 GasTeF 시설과 시험 결과를 설명하지만, 현재 접근 경로에는 machine-readable raw logger export가 확인되지 않았다.

### 2. Grüne/Sempert/KIT

- 0.37 dm³ 저장조의 3/4/10 mm 노즐 방출시험에서 공통 시간축 압력·온도·질량유량
- 밸브 개방 지연, 점화 시각·위치, 초기 저장조 압력·온도, 후단압력
- 비점화 방출과 점화 방출의 시험 ID 분리
- 원시 자료 대신 원저자 보관형 평가가 가능하면 pressure-decay와 time-to-half-pressure의 시험별 오차만 제공

### 3. Schefer/Sandia

- 고압 저장조 blowdown의 pressure-time·temperature-time·mass-flow trace
- 초기 약 413 bar 조건, 노즐 내경, 저장조 체적·형상, 방출 시작 정의
- 화염 길이·복사열 자료가 있으면 공통 시험 ID와 계측 위치
- 그림 디지털화 자료만 가능한 경우에는 독립 검증이 아니라 경계자료로만 사용한다는 조건 수락

### 4. Cal State LA HRS

- 비식별 station-side 충전 이벤트의 dispenser/line pressure, gas temperature, pre-cooler outlet temperature, mass flow, cumulative mass
- cascade bank 선택·밸브 상태·compressor/PCV/ESD 상태, 이벤트 시작·정지 사유
- 차량 압력·온도·SOC가 공통 시계열로 제공될 때만 station-to-vehicle 검증 후보로 분류
- 시설명·회사명·제조사·시리얼·정확한 날짜는 제거하고 이벤트 시작을 0초로 재기준

## 검증 방식

1. 데이터 관리자가 원자료를 보관한 채 채널 목록·단위·샘플주기만 먼저 확인한다.
2. 평가자는 결과를 보기 전에 모델 커밋, 입력 매핑, 포함·제외 규칙, 주요 지표와 holdout 분할을 해시로 고정한다.
3. 데이터 관리자가 고정 실행을 수행하거나 제한된 비식별 파일을 제공한다.
4. 결과는 시험별 pressure NRMSE, time-to-half-pressure 오차, temperature RMSE, 유량 오차와 bootstrap 불확도로 반환한다.
5. 실패한 시험도 모두 보고하며, 결과 확인 후 파라미터를 재조정하지 않는다.

## 비식별·권리 조건

- 회사·시설·주소·제조사·모델·시리얼·절대 날짜·절대 시각을 제거한다.
- 원시 행을 공개 저장소에 저장하지 않고, 파일 해시·스키마·집계 결과만 보관할 수 있다.
- 논문·재현성 자료에 시험별 집계치를 사용할 수 있는지 서면으로 확인한다.
- 원자료 재배포가 불가능하면 custodian 실행형 검증 또는 독립 검토자 참관형 결과를 요청한다.

## 주장 제한

이 요청으로 확보한 자료가 있어도 야외 제트화재·폭발 영향거리, 법정 안전거리, 규제 적합성, 운영자 대응 효과 또는 자율제어 성능을 자동으로 입증하지 않는다. 각 자료가 닫을 수 있는 구성요소와 한계를 결과 보고서에 명시한다.
