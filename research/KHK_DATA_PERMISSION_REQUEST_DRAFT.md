# Draft request: KHK hydrogen-station accident subset permission

**Subject:** Request for de-identified KHK hydrogen-station accident subset and publication permission

Dear KHK/METI data custodian,

We are validating an academic hydrogen-refuelling-station digital twin and a
deterministic, evidence-grounded operator decision-support system. We located the
FY2025 KHK high-pressure-gas accident case database and will respect the stated
copyright and no-redistribution conditions.

We request, if possible:

1. permission to extract a de-identified subset limited to hydrogen stations,
   compressed-hydrogen stands, dispensers, storage banks, compressors, valves,
   hoses, detectors and relief devices;
2. permission to use the subset to create a frozen, blinded expert-evaluation
   casebook for safety-response research;
3. permission to publish non-identifying aggregate counts and a reproducible
   codebook in an IJHE submission, while keeping the original records and any
   restricted fields under KHK/METI access control; and
4. any required citation, acknowledgement, embargo, review or data-security
   conditions.

We will not redistribute the original workbook, row-level incident text or a
downloadable mirror. Please advise which fields and derived summaries may be
published and whether a formal data-use agreement is required.

This is a draft only; no request has been sent.
