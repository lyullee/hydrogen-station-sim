# BAM/KETI 비식별 HRS 데이터 요청 초안

이 문서는 공개 연구에서 실제 충전소 모니터링과 차량 충전 시험이 보고된 BAM/KETI 연구팀에 보낼 수 있는 **검토용 초안**이다. 자동 발송하지 않으며, 접근 권한·윤리·재사용 조건이 확인되기 전에는 어떤 수치도 검증 결과로 사용하지 않는다.

공개 연구: [10.3390/app16157856](https://doi.org/10.3390/app16157856)  
시설 설명: [BAM H2Safety living lab](https://www.bam.de/Content/EN/Standard-Articles/Topics/Energy/Hydrogen/hydrogen-h2-filling-stations.html)

## 요청 목적

수소충전소 안전 디지털 트윈의 station-to-receiving-vessel 경계를 독립적으로 재생하고, 고정된 모델·프로토콜로 압력·온도·유량 예측을 평가하고자 한다. 원시 로그나 시설 식별정보를 공개 저장소에 복사하지 않고, custodian이 원본을 보관한 상태에서 비식별 이벤트와 해시·집계 지표만 전달하는 방식을 우선한다.

## 1단계: 스키마 파일럿

한 충전 이벤트의 헤더와 단위 사전만 제공해도 된다. 이 단계에서는 모델 적합, 파라미터 변경, 검증 점수 산출을 하지 않는다.

필수 역할:

- 공통 경과시간 또는 동기화 가능한 시간축
- 충전기/디스펜서 압력
- 전달가스 또는 경계 온도
- 질량유량 또는 누적 전달질량
- 공정 단계와 시작·정지 사유

## 2단계: 최소 비식별 묶음

서로 독립적인 충전 이벤트 3건을 요청한다. 가능하면 다음 채널을 추가한다.

- 차량 또는 리셉터클 압력·온도
- 선택 캐스케이드 뱅크와 밸브 상태
- 프리쿨러 출구 온도
- 압축기·PCV·ESD·fault 전이
- 누출검사·벤트·통신 상태

이 묶음은 station-side 또는 station-to-dispenser 경계 진단에 먼저 사용한다. 차량 채널이 세 이벤트 모두에 없으면 full-loop 검증으로 표현하지 않는다.

## 3단계: 독립 동결 holdout

가능한 경우 최소 8개의 독립 이벤트를 제공한다. 평가 담당자는 원시 결과를 보기 전에 모델 커밋, 채널 매핑, 포함 기준, 오류 지표와 분할을 해시로 고정한다. 결과는 이벤트별 압력·온도·질량·정지사유와 bootstrap 불확실성으로만 반환하며, 원시 행은 custodian이 보관한다.

## 비식별화와 권리 조건

- 회사명, 시설명, 주소, 제조사, 모델·시리얼, 달력 날짜와 절대 타임스탬프는 제거한다.
- 이벤트 시작을 0초로 재기준하고 파일명과 내부 태그도 가상 ID로 치환한다.
- 단위, 샘플주기, 결측 규칙, 센서 교정·불확도, 탱크 체적·정격압력은 역할 확인서로 제공한다.
- 분석된 집계 지표를 논문·재현성 자료에 사용할 수 있는지 서면으로 확인한다.
- 원시 데이터 재배포가 불가능하면 custodian 실행형 해시 고정 평가 또는 독립 리뷰어용 제한 패키지를 요청한다.

## 안전한 평가 경계

자료를 받더라도 결과가 자동으로 현장 안전거리, 규제 적합성, 사고 빈도, SAGA 효과성 또는 자율 제어 성능을 의미하지 않는다. 이 초안은 데이터 접근을 쉽게 하기 위한 요청 양식이며, 승인·독립 전문가 평가·동결 holdout을 거친 뒤에만 해당 주장을 검토한다.
