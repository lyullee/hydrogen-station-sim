# HySaM public dataset inventory (2026-10-14)

- DOI: `10.5281/zenodo.20590842`
- License: CC BY 4.0
- Decision: **inventory only; no IJHE validation gate promotion**.

The three workbooks contain time-series channels for temperature, pressure, flow and mass-related signals at a 0.5 s sampling interval. The public description identifies sampling-system experiments. The release does not provide an HRS storage-bank/compressor/dispenser topology, release geometry, or a synchronized station-to-vehicle trace. It is therefore retained as reusable signal and sampling-system context, not as independent HRS validation.

File hashes, row counts, channel names and the prohibited-claim boundary are recorded in the companion JSON.
