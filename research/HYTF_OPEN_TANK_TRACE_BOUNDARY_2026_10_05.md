# HyTF public tank trace boundary (2026-10-05)

The public [ArtCouteau/HyTF repository](https://github.com/ArtCouteau/HyTF) contains the machine-readable file [`190821_f70MPa_01.txt`](https://github.com/ArtCouteau/HyTF/blob/4482486fa9ab02360af364f3d1dad5ea48eabaf8/input/sensorData/190821_f70MPa_01.txt) at commit `4482486fa9ab02360af364f3d1dad5ea48eabaf8`. The file is 2,536 samples at 0.1 s spacing over 253.5 s, with two pressure channels, fourteen tank thermocouples, auxiliary rig channels and a 36 L tank geometry. The repository exposes the code under GPL-3.0; a separate data licence is not stated, so the raw file is referenced and hash-locked rather than copied into this project.

The record is useful for a separately pre-registered tank-thermal boundary or reproducibility screen. It does not include mass flow or transferred mass, vehicle/receptacle channels, station cascade/compressor/precooler/controller/ESD states, or written terms for derived journal metrics. It is therefore explicitly excluded from the complete station-to-vehicle holdout and from the SAGA effectiveness claim. The machine-readable boundary is in [`hytf_open_tank_trace_boundary_2026_10_05.json`](hytf_open_tank_trace_boundary_2026_10_05.json).
