# WSKBIJ apparatus metadata request draft

This draft is prepared for the dataset custodian. It has **not** been sent.

Subject: Metadata crosswalk request for DataverseNO DOI 10.18710/WSKBIJ

Dear Dr. Lach,

We are reproducing the public large-scale hydrogen explosion dataset published
as DOI `10.18710/WSKBIJ`. The raw pressure channels and summary workbook are
clear, but we could not find the spatial crosswalk needed for an
apparatus-resolved comparison. If it can be shared, could you please provide or
point us to publisher-authenticated metadata for:

1. the common coordinate origin and axes;
2. P01--P04 coordinates or their equal spacing and first-sensor location;
3. the per-experiment obstructed/unobstructed flag;
4. obstacle type, dimensions, blockage/open-area ratio and coordinates;
5. the physical coordinates represented by ignition-position codes 1--3;
6. ignition delay for each experiment;
7. nozzle origin and release direction; and
8. any available ambient temperature, pressure and wind record.

A machine-readable table keyed by experiment number would be sufficient. We
will cite the dataset and any associated method publication, preserve the
original CC0 terms, and report missing fields rather than infer geometry from
the measured overpressure.

Kind regards,

KGS - AI Safety Research Team
