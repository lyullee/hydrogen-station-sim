# FCH2RAIL raw-data request draft

Subject: Request for de-identified hydrogen train refuelling traces for independent digital-twin validation

Dear FCH2RAIL/DLR data custodian,

I am preparing an evidence-gated study of a virtual hydrogen-refuelling-station digital twin. We would like to request access to de-identified, machine-readable measurement data underlying the open article **Development, application and optimization of hydrogen refueling processes for railway vehicles** (DOI: [10.1016/j.ijhydene.2025.04.040](https://doi.org/10.1016/j.ijhydene.2025.04.040)).

The requested package is limited to data that can be shared under your terms:

- synchronized timestamps for each refuelling event;
- dispenser pressure, temperature and mass-flow channels;
- tank-module pressure, temperature and, where available, transferred mass or SOC;
- ambient and pre-cooling conditions;
- trailer/HRS source state, compressor/cascade state and protocol/ramp settings;
- channel dictionary, units, sample rates, calibration/quality flags, excluded-event reasons and maintenance markers;
- train/tank configuration metadata (capacity, nominal pressure, Type III/IV designation) without personal or commercially sensitive identifiers.

We will hash and quarantine the files before opening outcomes, freeze the scoring protocol and model commit before numerical evaluation, retain failed cases, and publish only aggregate derived metrics unless you grant broader permission. Please specify the data licence, citation requirements, embargo or access restrictions, and whether publication of derived pressure/temperature/flow errors is permitted.

This request is for independent validation; no article figure will be digitized as a substitute for raw measurements.
