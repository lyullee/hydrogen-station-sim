# Public component-data leads (2026-10-10)

This record closes two low-yield public-search branches. Both are retained as bounded component/design context and explicitly excluded from the P0 station-to-receiving-vessel validation gate.

- **HSR-Rig-Project**: a metal-hydride storage-reactor cycling rig with pressure, temperature, flow, cumulative transfer and absorption/desorption markers. It has no demonstrated HRS cascade/dispenser/vehicle receiving-vessel boundary.
- **Figshare 20928025**: CC BY 4.0 tables for a robotic hydrogen-filling system's path planning, link parameters and trajectories. It is design/robotics data, not synchronized fueling telemetry.
- **Zenodo 10.5281/zenodo.18213166**: a CC BY 4.0, 29-experiment two-stage metal-hydride compressor release with pressure, temperature and mass-flow channels. It is a component-validation lead; it has no HRS cascade, dispenser or receiving-vessel boundary.

The first preregistered channel screen used `Experiment 15.xlsx` after the protocol was frozen. The file contains a 20-minute single-tank compression trace with pressure, volumetric-flow and temperature families, but the flow unit and metal-hydride thermal boundary are not directly compatible with the station compressor model. The screen is therefore retained as a schema/boundary diagnostic only; no coefficient was fitted and no runtime parameter was changed. See [`public_mhc_experiment15_screen_2026_10_10.json`](public_mhc_experiment15_screen_2026_10_10.json).

To add an independent component-only check without reusing the consumed Experiment 15 trace, Experiment 16 was selected and its protocol frozen before workbook access. The resulting 1,186-record trace spans 1,185 s and contains monotonic elapsed time plus pressure, volumetric-flow and temperature families. It is retained as compatibility evidence only because the experiment is a single-tank metal-hydride compressor with `L/min` flow and an adsorption/thermal boundary that is not the station compressor model. See [`public_mhc_experiment16_holdout_protocol_2026_10_12.json`](public_mhc_experiment16_holdout_protocol_2026_10_12.json) and [`public_mhc_experiment16_screen_2026_10_12.json`](public_mhc_experiment16_screen_2026_10_12.json). No rows are committed, no numerical score is promoted, and no runtime parameter is changed.

The next high-impact action is therefore the privacy-safe three-event custodian intake defined in [`full_loop_raw_data_request_package_2026_10_05.json`](full_loop_raw_data_request_package_2026_10_05.json). Repeating a search for another article or design table will not close the open gate without receiving-vessel and controller channels.
