# Grüne (2014) public pressure-trace recheck — 2026-10-12

## Purpose

The Grüne pressure-decay gate remains open only if a complete, reusable
pressure–time trace can be obtained under a frozen pre-access protocol. This
recheck records whether the public paper and its linked sources provide that
trace. It is an evidence-availability audit, not a new fit and not a new
validation result.

## Sources reviewed

- [Publisher record](https://www.sciencedirect.com/science/article/pii/S0360319913020521)
- [KIT publication landing page](https://publikationen.bibliothek.kit.edu/110097219)
- [Public ICHS conference PDF](https://conference.ing.unipi.it/ichs2011/papers/133.pdf)
- [Public H2Tools preprint](https://h2tools.org/sites/default/files/2019-08/paper_120.pdf)
- [Official JHFC/JARI project archive](https://www.jari.or.jp/jhfc/)
- [Reported JHFC report index](https://www.jari.or.jp/jhfc/data/report/index.html) (unavailable at recheck; HTTP 404)

The H2Tools copy confirms the same experiment description and plotted
pressure-decay context, but does not expose a complete machine-readable trace
or a data-redistribution licence. The search also checked targeted public-data
indexes for a rights-cleared machine-readable pressure-time archive. The
JHFC/JARI route provides project
scope and report context, but no Grüne-specific pressure-time file or
supplementary raw trace was found.

## Finding

The public sources provide the experiment description, plotted results and
summary timing statements, but no complete machine-readable pressure trace
with a documented reuse path. The repository's existing digitisation of the
published figure contains 51 early-transient points only; it does not reach
the required half-pressure crossing. The conference PDF adds experimental
context but does not supply a reusable full trace.

The existing result therefore remains `PENDING_INELIGIBLE_FOR_JOINT_SCREEN`.
The runtime model, gate thresholds and manuscript claims are unchanged.

## Re-entry condition

Request a rights-cleared raw pressure-time file (including the complete
discharge endpoint, units, initial conditions and logger timing), freeze a new
protocol before opening it, and run the declared joint screen without fitting
to the outcome. Until then, the paper must describe Grüne as an unresolved
data-availability limitation rather than as a passing external validation.
