# Progress delta — 2026-10-13

## 새 실제 수소 방출 증거

Liang et al. (2026)의 1 mm 원형 노즐 고압 수소 방출 실험 Table 2 일곱
점을 전사하고, 기존 `DynamicLeakModel`을 변경 없이 실행했다. 생산
`Cd=0.8` 모델은 NRMSE 28.43%, 중앙 APE 39.05%, 평균 +38.45% 편향으로
기존 유량 스크린을 통과하지 못했다. 그러나 `Cd=1`인 실가스 계산은
논문의 Abel–Noble 이론값을 NRMSE 0.59%, 중앙 APE 0.81%로 재현했다.
오차의 지배 원인이 EOS가 아니라 방출계수/기하 경계라는 점을 분리했다.

결과를 본 뒤 프로토콜을 작성했으므로 이 비교는 post-access zero-fit
benchmark로만 기록했다. `Cd=0.6` 진단은 NRMSE 3.62%, 중앙 APE 4.29%였지만
생산 기본값으로 승격하지 않았다. 현재 Proust 자료까지 함께 보면 단일
범용 계수보다 노즐·배관·밸브·균열별 경계 모델과 새로운 미사용 캠페인이
필요하다. 검증 게이트 수와 준비도 백분율은 변경하지 않았다.

관련 산출물은 `LIANG_2026_RELEASE_BENCHMARK_2026_10_13.md`,
`liang_2026_release_benchmark_2026_10_13.json`, 고정 프로토콜, 전사 CSV,
실행기 및 자동화 테스트이다.

SAGA 근거 봉투에도 이 결과를 연결했다. 일반 답변에는 Proust의 0/3 결과와
함께 `Liang post-access, Cd=0.8 FAIL, 평균 +38.45% 편향, EOS parity PASS,
런타임 변경 없음`만 짧게 전달하고, 상세 근거에는 DOI·오차·유효계수 범위와
“현장 실측 안전거리 아님” 경계를 보존한다. 프롬프트 크기 제한도 유지했다.

## 실시간 재고량 기반 방출 규모 화면

피해영향평가가 순간 방출유량만 보여 주던 한계를 줄이기 위해, 실제 디지털
트윈 상태의 저장뱅크·차량 재고량과 런타임 설비 체적을 피해영향 결과에
연결했다. 현재 재고에서 동일 온도의 대기압 평형 재고를 뺀 방출 가능 모의
재고를 계산하고, Proust 공개 실험에 근거한 방출유량 민감도 하·상한으로
나눈 시간비를 함께 표시한다. 런타임 설정 체적은 HAZOP 표의 정적 모델 체적보다
우선하며, 계산 근거는 센서 분석·메인 SAGA·근거 봉투·직답 요약·한영 UI에
같은 필드로 전달된다.

이 값은 `CURRENT_RATE_RATIO_ONLY`로 고정했다. 압력감소, 열전달, 계속되는
유입, 밸브 폐쇄, 배관 잔류량을 적분하지 않으므로 압력 고갈·격리 완료·대피
완료·누출 종료 예상시간으로 사용하지 않는다. 독립 source-depletion holdout이
통과하기 전까지 이 한계를 LLM 프롬프트와 화면에 강제로 유지한다. 관련 산출물은
`RUNTIME_INVENTORY_DURATION_SCREEN_2026_10_13.md`와
`runtime_inventory_duration_screen_2026_10_13.json`이며, 준비도 게이트 수는
`132 PASS / 11 FAIL / 7 PENDING`이다. 새 PASS는 HyDelta 실제 수소
자연환기 실험을 가스 방출 대응에 연결하면서, 환기 상태만으로 안전 복귀를
판정하거나 H70 분산·현장 안전거리를 검증했다고 주장하지 못하게 하는 게이트다.

## 압축기 격리 후 유한 잔류재고 감압

기존 런타임은 저장뱅크·공통 헤더·디스펜서 호스에는 유한 재고를 적용했지만,
압축기 누출에는 별도 재고가 없어 고압 저장뱅크 전체를 누출원으로 대신했다.
그 결과 ESD와 압축기 경로 차단 뒤에도 고압 뱅크가 계속 누출되는 것처럼 보일
수 있었다.

압축기 토출 패키지와 짧은 매니폴드를 하나의 유한 질량·에너지 제어체적으로
추가했다. 압축기 유입, 선택 저장뱅크로의 유출, 밸브 개도, 누출, 벽체 열교환을
같은 상태벡터에서 적분한다. ESD가 작동하면 저장뱅크 재공급은 중단되지만
패키지에 갇힌 수소는 즉시 사라지지 않고 계속 방출되며 압력과 유량이 점차
감소한다. 이 상태는 API, HAZOP의 최종 토출 압력·온도, 센서 분석과 SAGA의
근거 봉투에 전달된다. 패키지 체적·연결 면적·초기압력은 API 입력으로 바꿀 수
있어 시설별 형상으로 교체할 수 있다.

결정론적 감사에서는 0.5 mm 누출과 ESD 이후 5초 동안 고압 뱅크 질량 변화가
수치상 0 kg으로 유지되고, 패키지 압력과 잔류 방출유량이 함께 감소했으며,
패키지 질량손실과 적분 방출량의 잔차는 약 1.10e-6 kg이었다. 관련 산출물은
`COMPRESSOR_PACKAGE_ISOLATION_AUDIT_2026_10_13.md`와
`compressor_package_isolation_audit_2026_10_13.json`이다.

이 결과는 내부 보존·토폴로지 감사이며 외부 검증이 아니다. 기본 0.020 m³
패키지 체적, 연결 등가면적 및 열전달 계수는 특정 제조사 압축기를 나타내지
않는다. 독립 수소 패키지 감압 시계열로 검증하기 전까지 상태는
`DEVELOPMENT_PHYSICS_UNVALIDATED`로 유지하며 현장 격리시간·누출량·안전거리를
확정하지 않는다. 따라서 준비도 게이트 수는 바꾸지 않는다.

## HyDelta 실제 수소 캐비닛 측정구간 스크리닝

HyDelta/Kiwa의 공개 실제 수소 자연환기 실험(DOI
`10.5281/zenodo.8164602`)에서 비표시용이 아닌 0.5 m³·4.0 m³ 캐비닛 8개
표 측정행을 런타임 피해영향 근거에 연결했다. 입력 누출 질량유량은 표 행을
선택하기 위한 Nm³/h로만 환산한다. 정확한 표 유량이면 해당 측정값을 재현하고,
두 표 유량 사이이면 같은 캐비닛 계열의 인접한 두 측정값과 LFL 전이 여부를
제시한다. 농도나 체적은 보간하지 않으며 0.125–5.8 Nm³/h 범위 밖, 0.5·4.0 m³가
아닌 체적은 `OUTSIDE_PUBLIC_*_DOMAIN`으로 닫힌다. 체적이 불명확한 미니 캐비닛
두 건은 정성적 경고 근거로만 남기고 수치 스크린에는 사용하지 않는다.

결과는 기존 HyRAM 농도·열복사·과압·위험거리를 덮어쓰지 않고 별도 필드로
API와 LLM 근거 봉투에 전달된다. HyRAM이 비가용이어도 표 근거 자체는 유지하되
피해영향 계산 성공으로 바꾸지 않는다. 모든 결과에는 DOI, CC BY 4.0, 독립 가스
재측정 필요, `safety_clearance_authorized=false` 및 H70 분산·검지기 배치·경보
설정·ESD 효과·현장 안전거리 미검증 경계가 붙는다.

8개 표 행 재현, 구간 판정, 범위 밖 폐쇄, LLM 투영 및 백엔드 비가용 경로를
자동화했다. 소스 해시 변경 뒤 HIAD 34/34와 KHK 범위 내 22/22 공개 사고 재생도
다시 통과했으며, 준비도는 `132 PASS / 11 FAIL / 7 PENDING`으로 유지된다. 이는
기존 HyDelta 근거 게이트를 더 엄격하게 만든 것이며 새로운 독립 검증 PASS를
추가한 것이 아니다.

## 검증 산출물 일괄 재생성

런타임·API·LLM 근거 소스를 수정할 때마다 서로 연결된 해시 산출물을 수동으로
재생성하던 절차를 `scripts/refresh_runtime_evidence_chain.py` 하나로 통합했다.
HyDelta, Type-IV, 공개 사고 라우팅, HIAD·KHK 재생, 추적성, 준비도 미러, 검증
공백·차단표, 데이터 커버리지와 IJHE 주장-근거표까지 13단계를 의존 순서대로
실행하며 최초 전체 실행은 56.0초에 모두 통과했다. 자식 프로세스 출력은 UTF-8로
고정하고 선택적 실행 기록에는 로컬 저장소 경로가 남지 않도록 했다. 이 자동화는
근거 일관성을 재생성할 뿐 실패·대기 중인 과학 검증을 PASS로 승격하지 않는다.
