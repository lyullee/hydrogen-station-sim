# KGS HRS code/data access recheck (2026-10-05)

The KGS-linked study reports six real HRS fueling scenarios with vehicle pressure, vehicle temperature and mass-flow measurements. Its open preprint is [10.21203/rs.3.rs-6248350/v1](https://doi.org/10.21203/rs.3.rs-6248350/v1), and the published article is [10.1007/s11814-025-00551-9](https://doi.org/10.1007/s11814-025-00551-9).

The paper points to a Google Drive code folder. An anonymous HTTP access check followed the redirect to `accounts.google.com` and retrieved zero files. This records the link as an unverified access/rights boundary; it does not infer that the authors lack the code or measurements. The synchronized station logger archive, channel dictionary, calibration data and reuse terms are still required before the six scenarios can become a frozen external holdout.

The source is therefore real-station provenance and a high-priority acquisition route, not numerical validation evidence. The request template remains [`KGS_HRS_DATA_REQUEST_DRAFT.md`](KGS_HRS_DATA_REQUEST_DRAFT.md).
