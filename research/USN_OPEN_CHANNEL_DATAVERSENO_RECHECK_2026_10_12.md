# DataverseNO recheck — USN open-channel hydrogen dispersion data

The public record [10.23642/USN.26117989](https://doi.org/10.23642/USN.26117989) was rechecked independently of the existing Figshare intake. The DataverseNO record exposes 22 experiment ZIP files and a README under CC BY 4.0. A downloaded package was hash-locked locally; raw ZIPs and CSV rows remain outside version control.

The recheck confirms the existing 22 experiments, 29 concentration channels per CSV, temporal flow/pressure fields and separate hydrogen-sensor time observations. The archive-level SHA-256, per-file Dataverse MD5 values and local MD5 comparisons are retained in `usn_open_channel_dataverseno_recheck_2026_10_12.json`.

This is a provenance/checksum improvement, not a new validation score. Because the archive was opened before the spatial diagnostic was scored, it is **post-access development evidence only** and is not an independent holdout. A future validation claim requires a new untouched archive and a protocol frozen before numerical access. The data do not provide an HRS controller, cascade, dispenser, vehicle/receptacle or ESD channel, so they cannot close the station-to-vehicle full-loop gate or change runtime parameters.
