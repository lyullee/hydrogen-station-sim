# 독립 검증 원자료 요청 사양서

작성일: 2026-10-14  
목적: 수소충전소 안전 디지털 트윈의 남은 독립 물리 검증을 재현 가능한 방식으로 닫기 위한 최소 자료 요청서

이 문서는 데이터를 공개하거나 저장소에 원자료를 복사하기 위한 문서가 아닙니다. 원자료는 소유기관의 통제 환경에 보관하고, 프로젝트에는 권리 확인서·파일 해시·집계된 검증 결과만 남깁니다. 회사명, 충전소 위치, 정확한 날짜, 제조사·모델명·시리얼번호·운영자 식별정보는 제출본에서 제거하거나 범주화합니다.

## 공통 제출 조건

각 사건 또는 실험마다 다음 항목을 함께 제출해야 합니다.

| 항목 | 최소 요구사항 |
|---|---|
| 원자료 | CSV, MAT, HDF5, Parquet 중 하나. 압축·변환 전 원본 해시를 보존 |
| 시간축 | 단조 증가한 UTC 또는 상대초. 샘플링 주기와 누락 구간 명시 |
| 단위 | 각 채널의 단위, 센서 위치·방향, 영점·범위·정확도 |
| 사건 경계 | 시작·밸브 개방·정상화·종료 시각. 실험자가 기록한 사건 로그 포함 |
| 장치 조건 | 저장용기 체적, 초기 압력·온도, 개구 직경/형상, 방출 방향, 주변 압력·온도 |
| 권리 | 검증 목적 사용권, 재현 검토자 접근권, 결과 공개 가능 범위 |
| 동결성 | 모델·프로토콜을 읽기 전에 원자료를 전달했다는 custodian 확인 |

원자료에 민감한 값이 포함되면 실제 값 대신 일관된 익명 ID와 범주화된 값으로 제공할 수 있습니다. 단, 수치 검증에 필요한 물리량·단위·시간 정렬은 보존되어야 합니다.

| `preslhy_blowdown_external_validation` | 최소 12건, 노즐·압력군 3개 이상 | 저장조 압력·온도, 질량유량 또는 질량, 개구/노즐 치수, 방출 시간, 주변 조건 | 기존 공개 묶음의 허용 기준에서 joint pass fraction 미달 |
| `preslhy_partb_ambient_external_validation` | 대기 방출 5건, 노즐 2개·압력군 2개 이상 | 위 채널 + 방출 방향·경계조건·계측 불확도 | 대기 조건별 독립 holdout 부족/기준 미달 |
| `preslhy_revised_holdout_validation` | 대기 4건 이상, 노즐·압력군 2개 이상 | 위 채널 + 사전 동결된 사건 선택표 | revised holdout joint pass 미달 |

| `grune_2014_pressure_decay_validation` | 최소 15개 시점 + 초기압력 절반 교차점 | 4 mm 방출의 기계 판독 압력-시간 표, 체적·초기상태·주변조건, 재사용 허가 | 공개 도표는 절반압력 교차 전 끝나 기계 검증 불가 |

## 데이터 수령 후 고정 절차

1. 소유기관이 원자료 권리·익명화·사전 결과 접근 여부를 서명 또는 전자 기록으로 확인합니다.
2. 프로젝트는 원자료를 별도 통제 저장소에 보관하고 SHA-256과 파일 목록만 커밋합니다.
3. 각 게이트의 기존 protocol JSON을 수정하지 않고, 새 holdout용 protocol을 원자료 접근 전에 생성합니다.
4. 모델 실행 후 PASS/FAIL을 모두 보존합니다. 실패한 사건을 제거하거나 임계값을 바꾸지 않습니다.
5. 저장소에는 채널 수·시간 범위·오차 요약·해시·권리 경계만 공개하고 원시 행은 공개하지 않습니다.
6. readiness audit을 재생성하고, 독립 외부검증으로 통과한 게이트만 논문 본문 수치 주장에 사용합니다.

## 현재 범위에서 자료가 없어도 진행 가능한 항목

- 논문 제출 메타데이터·CRediT·이해상충·재정지원·AI 사용 선언은 저자 확인만 받으면 닫을 수 있습니다.
- 공개 데이터 검색 결과와 각 검증의 claim boundary는 이미 기록되어 있으며, 추가 검색을 검증 통과로 집계하지 않습니다.
- 실제 station-to-vehicle 동기 원자료가 없으면 해당 정확도 주장은 하지 않고 논문의 한계로 유지합니다.

이 사양서는 검증 게이트를 통과시키기 위한 요구사항이지, 자료가 없을 때 PASS를 만들어내는 대체 근거가 아닙니다.
