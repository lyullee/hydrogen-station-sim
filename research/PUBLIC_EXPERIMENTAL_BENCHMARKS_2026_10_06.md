# 공개 실험 근거와 적용 범위

`public_experimental_benchmarks_2026_10_06.json`은 공개된 실제 수소 충전
실험에서 추출한 집계값을 디지털 트윈과 LLM의 근거 문맥에 연결한다.

## 반영한 근거

- NREL H2FillS의 7탱크 HDVS 실측 로거는 공통 시간축의 호스 압력·온도와
  탱크 압력·온도·질량을 제공한다. 이 자료는 탱크·호스 경계의 개연성
  점검과 동결된 탱크 모델의 회귀 입력으로만 사용한다.
- DOE/NREL 고유량 HD 충전 실험 보고서는 73 kg 이송, 423.5 s 총 충전,
  평균 172.3 g/s, 피크 483.33 g/s, APRR 9.9 MPa/min, H70 프로토콜을
  보고한다. 이 값은 모의 충전 속도·압력 상승률·충전 시간의 범위를
  점검하는 기준으로 사용한다.
- 한국가스안전공사가 제공한 실제 HRS 6개 충전 시나리오를 검증한 공개
  논문은 차량 탱크 압력·온도와 질량유량을 비교하고, 온도 R² 평균 94.5%,
  압력 R² 평균 96.7%, 충전시간 287.8–421.7 s를 보고한다. 원시 로그나
  설비 제어 상태는 공개되지 않았으므로 집계 운전범위 근거로만 연결한다.
- NIST Field Test Standard 연구는 실제 소매 디스펜서에서 35 MPa 시험용기를
  대상으로 압력·온도와 독립 질량계측을 수행한 7개 수소 시험 드래프트와
  방법 간 최대 1.53% 차이를 보고한다. 원시 시계열과 디스펜서 제어 상태는
  공개되지 않았으므로 탱크·계측 경계와 불확도 문맥으로만 사용한다.
- USN Dataverse의 공개 CC BY 자료는 실제 수소를 사용한 개방형 직사각 채널
  분산 실험 22건의 압력·질량유량·29개 수소 검지기 채널을 제공한다
  ([DOI 10.23642/USN.26117989](https://doi.org/10.23642/USN.26117989)).
  원 논문 Table 1의 29개 x/y/z 좌표는 별도 메타데이터로 고정했지만,
  원시자료 열람 뒤에 좌표 holdout을 구성했으므로 독립 공간 holdout으로
  승격하지 않는다. 현재는 사고 모델의 저압 누출·검지 응답 범위 진단
  근거로만 등록하고 충전소 안전거리 검증으로 주장하지 않는다.
- USN의 공개 CC BY 점화 압력상승 자료는 동결된 절차로 27건을 평가해
  peak overpressure MAE 약 0.672 kPa와 27/27 primary pass를 기록한다.
  이 결과는 `public_ignited_pressure_peaking_validation`으로 LLM에 연결해
  점화·과압 시나리오의 component 근거로 사용하지만, 실외 H70 충전소,
  ESD 동작, 대피거리 또는 SAGA 대응효과 검증으로 확대하지 않는다
  ([DOI 10.23642/USN.17934047](https://doi.org/10.23642/USN.17934047)).

## 모델과 LLM에 적용하는 방식

LLM 근거 봉투의 `public_experimental_benchmarks`에 공개 출처별 식별자,
집계값, 사용 가능한 검증 경계와 사용 금지 범위를 넣는다. 따라서 답변은
실험 범위와 모의 결과를 비교할 수 있지만, 공개 보고서에 없는 행 단위
풀루프 로그를 만들어 내거나 사고 확률·안전거리를 단정할 수 없다.

비공개 운영 로그는 별도의 시간순 경계조건 홀드아웃으로 처리한다. 원본
행·사이트·운영자·제조사·태그명은 저장소와 LLM 문맥에 들어가지 않으며,
집계 보정값도 일반 기본값에 자동 적용하지 않는다.

## 남은 검증 공백

공개 자료에는 station controller/cascade state, ESD·밸브 피드백, 노즐·
리셉터클, 차량 프로토콜이 동시에 포함된 재현 가능한 풀루프 행 데이터가
없다. 따라서 이 반영은 운전 범위와 부분 경계 검증을 강화하지만, 전체
충전소 예측 정확도나 현장 안전 인증을 의미하지 않는다.
