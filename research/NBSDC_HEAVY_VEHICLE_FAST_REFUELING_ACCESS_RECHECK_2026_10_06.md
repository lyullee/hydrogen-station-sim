# 공개 대용량 수소 고속충전 데이터 접근 재점검

국가 기초과학 데이터 포털의 공개 메타데이터와 파일 트리를 확인했다. 자료 설명에는 대유량 디스펜서의 저압 질소·고압 수소 충전 시계열, 병 온도·유량, 단일 용기 평균 충전속도와 최대 유량 시험이 포함되어 있다. 저압 시험 설명에는 100 ms 기록과 SAE J2601-5 참조가 명시되어 있어, 차량측 전이 동특성 검증에 유용한 후보이다.

현재 포털은 설명 파일과 파일 목록은 비로그인 상태에서 보여 주지만, 수치 데이터 다운로드에는 데이터 신청이 필요하다. 실제 수치 파일을 우회해서 받지 않았고, 원시 행도 저장소에 복사하지 않았다. 따라서 이 자료는 현재 **실험 근거 및 취득 후보**이지 외부 검증 결과가 아니다.

신청이 승인되면 먼저 파일 해시·사용권·채널 사전·단위·시계 규칙을 기록하고, 모델과 합격기준을 고정한 뒤 독립 holdout을 분리한다. 시험용 용기 데이터는 실제 차량 데이터와 동일하다고 가정하지 않으며, 시험 매핑을 확인한 경우에만 압력·온도·유량 trace로 비교한다. 승인된 워크북을 읽기 위한 경계검사 로더는 [`src/h2station/nbsdc_ingest.py`](../src/h2station/nbsdc_ingest.py)에 있다.

현재 판단과 신청 필드는 [`nbsdc_heavy_vehicle_fast_refueling_access_recheck_2026_10_06.json`](nbsdc_heavy_vehicle_fast_refueling_access_recheck_2026_10_06.json)에 고정했다.
